# Therly Studio Media
Public media delivery for authorized Therly Studio social posts via Metricool.

Base URL: https://wemerson123.github.io/therly-media/

Store only finished, authorized MP4 files under `media/`, with unique immutable filenames. Never upload source templates, secrets, private client data or licensed source assets. The index requests noindex; robots.txt requests no crawling. These requests do not provide privacy or access control.
